# watplan

Aplikacja napisana w Go (Golang), która pobiera plan zajęć ze strony wybranego wydziału WAT i przetwarza go na przejrzysty harmonogram.

## Funkcje
- Automatyczne pobieranie planu zajęć ze strony wydziału
- Parsowanie i formatowanie planu do łatwo dostępnej postaci

## Instrukcja obsługi
*Instrukcja w trakcie przygotowywania — projekt jest na wykończeniu i zostanie uzupełniony wkrótce.*
