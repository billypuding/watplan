# WATplan

## Komentarze w kodzie

- Nie pisz żadnych komentarzy w kodzie: ani w Go, ani w HTML, CSS i JS.
- Wyjątek: dyrektywy, które tylko wyglądają jak komentarze, a są potrzebne do działania, np. `//go:embed`, `//go:build`, `//go:generate`. Tych nie ruszaj.
- Po zmianach w Go uruchom `go build ./...` i `go vet ./...`.
